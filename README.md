# ⚔️ BallsFightingZ

An open-source physics-based ball combat simulation and arena game. Fight against AI opponents in multiple battle setups or experiment freely in sandbox mode.

## 🚀 Game Modes
* **1v1 Duel**: Test your combat mechanics against a single AI.
* **Team Battles**: Dynamic 2v2 and 3v3 team skirmishes.
* **Sandbox Chaos**: Unrestricted free-for-all mode to test collision physics and multi-agent interactions.

## 🛠️ Tech Stack
* **Client**: HTML5 Canvas & Vanilla JavaScript (`index.html`)
* **Backend Options**: Node.js (`server.js`) / Python (`server.py`)
* **Launcher**: Batch script (`PLAY.bat`)

## 🎮 How to Run
1. You can run this in any Like vs code or an html viewer
